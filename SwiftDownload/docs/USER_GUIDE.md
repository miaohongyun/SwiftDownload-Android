# 极速下载 · 用户手册

适用于 **v2.8.0**（versionCode 13）。版本变化见 [CHANGELOG.md](CHANGELOG.md)。

> 这是一份"怎么用"的说明。想了解内部实现与设计约束，看 [ARCHITECTURE.md](ARCHITECTURE.md)；
> 想看每个版本改了什么，看 [CHANGELOG.md](CHANGELOG.md)。

---

## 1. 它是什么

一个装在自己手机上的下载工具，把常见的几种下载场景收在一个 App 里：

- **普通文件**：HTTP/HTTPS 直链，多线程 + 断点续传。
- **网页视频**：内置浏览器播放网页视频时自动识别 `m3u8` / `mp4`，可以选清晰度。
- **磁力 / BT**：聚合 5 个磁力搜索源，内置 BT 引擎。
- **边下边播**：视频没下完也能先看，缺的部分边看边补。
- **投屏**：把下好的视频通过 DLNA 推到电视/盒子上。
- **文件管理**：排序、打开、分享、重命名、删除。

它**不是**万能视频下载器。会员墙、动态签名、加密直播这类受平台保护的内容，不在能力范围内，详见第 13 节。

## 2. 安装与第一次启动

### 2.1 安装

1. 用 `./scripts/build.sh` 构建 Release APK（`app/build/outputs/apk/release/app-release.apk`），传到手机安装。
2. 点击安装，系统可能提示"允许安装未知来源应用"，按提示授权即可。
3. 覆盖安装旧版本时，任务记录与设置会保留（数据库会自动迁移）。

> 签名与 v2.3 ~ v2.5.2 同源，可以直接覆盖升级；如果系统提示"签名不一致"，说明装的是别的来源改包，需要先卸载（会丢任务记录）。

### 2.2 首次启动会看到什么

- **通知权限**（Android 13+）：建议允许。下载在后台进行时，通知栏会显示进度；下载完成也会发提醒。
- **存储位置提示**：如果系统不允许写公共 `Download` 目录，App 会自动改用应用专属目录，并弹一次提示。

### 2.3 文件到底存在哪

| 系统情况 | 实际路径 |
| --- | --- |
| 公共下载目录可写（Android 9 及以下、部分厂商 ROM） | `内部存储/Download/` |
| Android 11+ 标准分区存储 | `内部存储/Android/data/com.swift.download/files/Download/` |

第二种路径在文件管理器里可能显示为「极速下载」而不是包名。手动找：
`手机"文件"App → 内部存储 → Android → data → com.swift.download（或"极速下载"）→ files → Download`。

开启"文件自动分类"后，会在下载根目录下多出 `视频/`、`音频/`、`图片/`、`文档/`、`压缩包/` 等子目录；BT 任务固定在 `BT/` 子目录。

## 3. 界面总览

底部四个入口：

| 页面 | 用途 |
| --- | --- |
| **浏览器** | 多标签网页浏览、首页书签、磁力引擎入口、视频嗅探 |
| **传输** | 所有下载任务：进度、速度、暂停/继续、重下、删除、边下边播、投屏 |
| **文件** | 浏览下载目录，排序、打开、分享、重命名、删除 |

## 4. 下载普通文件

### 4.1 三种开始方式

**方式一：剪贴板（最省事）**

复制一个 `http://` 或 `https://` 直链，打开 App 切到"传输"页，顶部会出现"检测到已复制的下载链接"卡片：

- 点「立即下载」开始；
- 点「忽略」不再提示这个链接。

**方式二：新建任务**

传输页点「＋ 新建下载任务」，粘贴链接，可选文件名，点「开始下载」。

**方式三：从别的 App 分享**

在浏览器、聊天软件里分享链接给「极速下载」，会直接建任务。磁力链接与 `.torrent` 文件同样支持。

### 4.2 线程数怎么选

传输页右上角「设置」里可调 **1–16**，默认 4。

- 线程多不一定更快：很多服务器限制单 IP 连接数，线程太多反而被拒或变慢。
- 建议先 4，慢的话试 8；再高收益通常很小。
- 服务器不支持 Range（分段请求）时，App 会自动退回单线程，这是正常行为。

### 4.3 断点续传

- 下载中的任务暂停、App 被杀、手机重启，都会保留 `.swiftprog` 进度文件。
- 再次开始时，从已完成的字节处继续，不会从头下。
- 服务器文件变了（总大小与上次不一致）时，旧进度会被判定失效，自动从头下载，避免拼出新旧混合的坏文件。

### 4.4 那些"下载失败"提示是什么意思

v2.5.2 起，App 不再"假装成功"。下面这些错误都表示**服务器返回的数据不符合预期，App 主动拒绝写出坏文件**：

| 提示 | 含义 | 怎么办 |
| --- | --- | --- |
| `服务器未按 Range 返回分段（HTTP 200），已停止以避免文件损坏` | 多线程请求被服务器当成整文件返回 | 把线程数改成 1 重下；或换一个下载源 |
| `Content-Range 起点不符（期望 X，实际 Y）` | 服务器返回了错误区间的数据 | 换源；或单线程重下 |
| `HTTP 206 缺少 Content-Range` / `无法解析 Content-Range: …` | 服务器返回的区间头不完整 | 换源 |
| `分段数据不完整：还缺 N 字节（已收 M）` | 连接提前断开、响应被截断 | 点「继续」重试；反复出现就换源 |
| `文件大小在下载过程中变化（期望 X，实际 Y）` | 服务器内容在下载期间被替换，或声明的大小不准 | 该直链本身有问题，换源 |
| `合并文件失败（.part 无法改名或长度不符）` | 落盘/合并阶段出错，或存储空间不足 | 检查剩余空间；重下 |

这类失败**不会**留下一个"看起来下完了、其实播不了"的文件。任务会停在失败状态，可以重试或换链接。

## 5. 网页视频嗅探与清晰度选择

1. 切到「浏览器」，打开有视频的网页。
2. 页面开始播放后，如果 App 识别到 `m3u8` 或 `mp4` 请求，会弹出"发现视频"。
3. `m3u8` 会列出各档清晰度（分辨率 + 码率），选一档下载；`mp4` 直链直接询问是否下载。
4. 下载会自动带上当前网页地址作为 `Referer`，用于通过常见的防盗链检查。

识别的是**页面实际加载的媒体地址**，不依赖任何平台私有接口。因此：

- 能识别：普通 HLS 播放器、大多数影视站、测试流。
- 不能识别：B 站/抖音等的会员内容、需要登录或动态签名的地址（这些地址几分钟就过期，外部工具无法稳定下载）。

解析失败时，App 会退化为按原始地址下载（由引擎自动选最高码率）。

## 6. m3u8 / HLS 的支持边界（重要）

v2.6.0 起支持 **AES-128 加密**与 **`EXT-X-BYTERANGE` 分片**；v2.7.0 起新增 **fMP4（`EXT-X-MAP`）** 与 **TS 无损封装 MP4**。以下是能力边界：

| 特性 | 行为 | 说明 |
| --- | --- | --- |
| `#EXT-X-KEY: METHOD=AES-128` | 自动下载密钥并解密后拼接 | 支持显式 IV；未给 IV 时按分片序号推导 |
| `#EXT-X-BYTERANGE` | 按 `Range` 请求指定字节区间 | 服务器忽略 Range 时本地截取 |
| `#EXT-X-MAP`（fMP4 初始化段） | 先下载 init 段写文件头，再按序拼接 `.m4s` | 输出标准 `.mp4`；支持 init 段的 BYTERANGE |
| 传统 TS 流封装 MP4 | 下载完成后无重编码混流为 `.mp4` | 默认开启；编码不兼容时静默保留原 `.ts`，不会失败 |
| `#EXT-X-KEY: METHOD=SAMPLE-AES` 等 DRM | 开始前明确拒绝 | 只支持 AES-128，其余加密无法正确解密 |

其他行为：

- 传统 TS 流输出 **`.ts`**（可在设置里开启完成后自动封装为 `.mp4`）；fMP4 直接输出 **`.mp4`**。
- 分片 4 线程并发下载，单个分片失败会自动重试 3 次；暂停/继续时已完成分片跳过，未完成回滚后重下。
- 下载进度与速度会以 1 秒节流显示在通知栏（总大小按已完成分片均长动态估算）。
- 同一列表内多次更换密钥也能正确处理（每个分片绑定当时生效的 Key）。
- 分片地址是相对路径时会自动补全为绝对地址。
- 服务器不返回 `Content-Length` 的直播流可以按未知长度单线程下载，但这类任务不支持断点续传。

## 7. 磁力搜索与 BT 下载

### 7.1 三个入口

1. 浏览器首页点「磁力引擎」，输入关键词，从结果里选一条下载。
2. 网页里点 `magnet:` 链接，确认后建任务。
3. 从别的 App 分享磁力链接或 `.torrent` 文件。

### 7.2 结果怎么挑

- **来源数**：有多少个搜索源返回了同一条资源。越多说明传播越广。
- **做种数**：当前有多少完整副本在线。越高越容易下完。
- 相同 infohash 的结果会自动去重合并，不会出现一堆重复项。

### 7.3 "准备就绪（等待元数据…）"是什么

BT 任务需要先从其他节点拿到种子元数据（文件列表、大小），冷门资源可能要等 **1–3 分钟**。这段时间任务显示"准备就绪"，文件名可能是"磁力任务 xxxx"。

- 拿到元数据后会自动变成真实文件名并开始下载，落盘路径也会同步更新。
- 超过等待上限仍拿不到，会明确报失败（不会永远挂着）。
- 元数据到达后，任务卡会出现「选择文件」：可勾选/取消种子内的单个文件，未勾选的不会被下载。
- 「顺序下载」开关让视频文件的前置内容优先完成，适合提前预览；已有完整视频时会出现「预览」按钮。

### 7.4 搜索源管理

「我的 → 磁力源管理」：

- 开关某个源；
- 长按源卡片修改搜索地址（地址里要保留 `{kw}` 占位符）；
- 恢复默认。

某个源失效时，搜索会自动跳过它，不影响其他源返回结果。

## 8. 边下边播（视频没下完先看）

条件：**HTTP 视频直链**任务，且服务器返回了 `Content-Length`。BT 任务不支持。

操作：传输页找到该任务 → 点「边下边播」→ 选择播放器打开。

建议装 **VLC** 或 **MX Player**；部分系统自带播放器对 `127.0.0.1` 本地地址支持不好。

实际行为：

- 已下载的字节直接读盘；缺的字节由本地服务器向源站拉取，同时回写给下载引擎，不重复下载。
- 你关掉播放器 **8 秒**后，App 自动恢复多线程把剩余部分下完。
- 播放器拖动进度条是否顺畅，取决于视频封装：`mp4` 的索引（moov）在文件末尾时，拖动会没反应；App 检测到这种情况会提前提示。
- 播放期间任务仍算"下载中"，进度会继续前进。

## 9. 投屏到电视（DLNA）

1. 手机和电视/盒子连**同一个 Wi-Fi**。
2. 电视端打开 DLNA / 多屏互动（不同品牌叫法不同，有的默认关闭）。
3. 在传输页已完成的视频任务上点「投屏」，或在文件页长按视频选「投屏播放」。
4. 从搜到的设备里选电视，开始播放，之后用电视遥控器控制。

投屏成功后对话框会**保留**并显示"投屏中"，想结束时点「停止投屏（恢复电视原画面）」。停止后会释放本地文件服务。

找不到设备时依次检查：是否同一 Wi-Fi、电视 DLNA 是否开启、路由器是否开了 AP 隔离（客户端隔离）。

## 10. 文件管理

「文件」页显示下载根目录（含 BT 子目录）。

- **排序**：时间 / 名称 / 大小，升序或降序，选择会记住。
- **单击**：用系统关联的应用打开。
- **长按**：打开、分享、投屏（视频）、重命名、删除。
- **重命名**：只接受纯文件名，不能包含 `/`、`\`，也不能是 `.`、`..` 或以 `.` 开头；改名成功后会同步更新任务记录里的路径。
- `.part` 等临时文件不会显示。

## 11. 下载设置

路径：「我的 → 下载设置」。**所有开关默认关闭**（m3u8 识别默认开启），修改后只对**新任务**生效。

| 设置项 | 说明 |
| --- | --- |
| **最大同时下载** | 1–5，默认 3。超出的任务进入排队，显示"等待空闲队列"，有任务结束会自动补位。 |
| **限速** | 全局上限，单位 MB/s，`0` = 不限。也可以只给单个任务限速：传输页任务卡上的「限速」按钮，设过会显示"限速 5M"。 |
| **仅 Wi-Fi 下载** | 移动数据下新任务进入排队（显示"等待 Wi-Fi 连接"），回到 Wi-Fi 自动开始。 |
| **下载时段** | 只在指定小时区间内下载，支持跨零点（如 23 点 → 7 点）。区间外显示"等待允许下载时段"。 |
| **文件自动分类** | 按类型放入 `视频/`、`音频/`、`图片/`、`文档/`、`压缩包/` 等子目录。 |
| **支持 m3u8 流媒体** | 默认开。关掉后 `.m3u8` 地址按普通文件处理。 |
| **HTTP 代理** | 填主机与端口（默认 `127.0.0.1:7890`），对直链下载与磁力搜索生效，新任务生效。 |

限速、时段、代理三项都有显式「保存」按钮；时段与代理点击输入行也会保存。改了没反应时，先确认点到了「保存」。

> v2.6.0 起，「仅 Wi-Fi」与「下载时段」**每秒实时检查**：正在下载的任务若切到移动数据或超出时段，会自动挂回排队并显示等待原因；条件恢复后自动继续。限速仍需通过任务卡按钮单独设置。

## 12. 任务操作一览

传输页每个任务卡上的操作：

| 操作 | 行为 |
| --- | --- |
| **暂停** | 停止当前传输，保留断点数据。 |
| **继续** | 从断点继续。BT 任务会优先恢复会话里的种子，而不是重新添加。 |
| **边下边播** | 仅 HTTP 视频任务，见第 8 节。 |
| **投屏** | 仅已完成视频，见第 9 节。 |
| **限速** | 给该任务单独设上限；`0` 取消。 |
| **重新下载** | 清空该任务的所有进度与临时文件，按**原始参数**从头重建（m3u8 保留清晰度与 Referer，种子不再被当磁力链接）。 |
| **刷新链接** | 直链过期时用。输入新地址后会清掉旧 `.part` / 进度 / HLS 状态，按新链接重新探测并从 0 开始。**旧进度不会保留。** |
| **删除** | 两个选项：「删除」连文件一起删；「仅删任务」保留已下载文件。删除活动中的 BT 任务会同时停止做种。 |

批量操作在传输页工具栏：全部暂停、全部继续、清除完成。

## 13. 已知限制（不是 bug）

1. **HLS 只支持 AES-128 与 ByteRange**；fMP4（`EXT-X-MAP`）与 SAMPLE-AES 等 DRM 会明确拒绝，见第 6 节。
2. **边下边播只支持 HTTP 直链**，不支持 BT；服务器不返回 `Content-Length` 时也无法使用。
3. **未知长度流不支持断点续传**，只能从头完整下载。
4. **需要登录/动态签名的平台视频下不了**，这是地址本身的性质，不是解析能力问题。
5. **投屏依赖电视的 DLNA 兼容性**，不同品牌差异较大。
6. **局域网投递默认关闭且无鉴权**，只应在可信 Wi-Fi 下临时开启，用完及时关闭。
7. **通知栏进度**需要通知权限；拒绝后下载仍能进行，但看不到进度。
8. **已完成的 BT 任务在服务运行期间仍可能继续上传（做种）**，删除任务时只对仍在任务表中的活动种子停止做种；服务停止或 App 退出后全部结束。

## 14. 常见问题

**Q：通知栏没有进度？**
首次启动的权限弹窗点了"拒绝"。到系统设置 → 应用 → 极速下载 → 通知，手动打开。

**Q：重启手机后任务还在吗？**
在。运行中/等待中的任务会自动重建并继续；你主动暂停的任务保持暂停。

**Q：下载速度很慢？**
先看设置里有没有限速或时段；再试把线程数调到 8。服务器自身限速时，多线程无法突破。

**Q：任务一直停在"准备就绪"？**
BT 任务在等元数据，冷门资源需要 1–3 分钟。HTTP 任务出现这个状态通常是服务器没返回文件大小。

**Q：链接失效了怎么办？**
在失败任务上点「刷新链接」，粘新地址。注意这会清空旧进度，从头下载。

**Q：提示"没有权限"？**
Android 11+ 的分区存储限制。App 会自动降级到应用专属目录；仍失败时，到系统设置给 App 的"文件和媒体"权限打开。

**Q：为什么下载完成却播不了？**
先确认是不是 HLS 的加密/fMP4/ByteRange 流（App 会在开始前拒绝，不会产出文件）。如果是普通文件，检查扩展名与实际格式是否一致——有些直链返回的是网页而不是视频。

**Q：能同时下多少个任务？**
默认最多 3 个同时运行（可在「下载设置 → 最大同时下载」调到 1–5）。超出的任务排队显示"等待空闲队列"，有任务结束会自动补位。

**Q：升级会丢数据吗？**
覆盖安装不会丢任务记录和设置。卸载会清掉应用专属目录里的文件（公共 `Download` 目录的文件不受影响）。

## 15. 数据与清理

- 任务记录存在应用内 SQLite，卸载即清空。
- 临时文件：下载中的 `<文件名>.part`、进度 `<id>.swiftprog`、HLS 状态 `<id>.m3u8state`，完成或删除任务后会清理。
- 想彻底清空：先在传输页「清除完成」并删除任务，再卸载 App。
- 想保留文件只清任务：删除时选「仅删任务」。

## 16. 高级选项与哈希校验（v2.6.0 新增）

**新建任务高级选项**：「＋ 新建下载任务」对话框底部可展开「高级选项」，填写自定义文件名、
Referer、Cookie、User-Agent。需要登录或防盗链的站点，可从浏览器复制这些信息填进来。

**哈希校验**：文件页长按文件选「校验哈希 / 详情」，或传输页已完成任务点「校验哈希」。
后台一次算出 MD5、SHA-1、SHA-256，可粘贴官方提供的哈希值（32/40/64 位十六进制，
带不带 `md5:` / `sha1:` / `sha256:` 前缀都行）一键比对是否一致。

## 17. 局域网投递（v2.6.0 新增）

1. 手机与电脑连同一个 Wi-Fi。
2. 「我的 → 局域网传链接」开启，面板会显示 `http://<手机IP>:8877/`，可点「复制地址」。
3. 电脑浏览器打开该地址，可以：
   - 粘贴 `http(s)` 直链或 `magnet:` 磁力链接，点「添加」；
   - 上传 `.torrent` 文件推送种子任务；
   - 查看当前下载任务列表与进度（每 2 秒自动刷新）。
4. 用完回到「我的 → 局域网传链接」关闭。

> 这个面板**默认关闭、没有密码**，同一 Wi-Fi 下的任何人都能访问。只建议在可信网络临时开启，
> 用完立即关闭。若未连 Wi-Fi（或只有 VPN 虚拟网卡），会提示无法开启。

## 18. 完成后导出与投屏

- Android 11+ 若下载目录被系统限制到应用专属空间，任务完成后会自动导出一份到公共
  `Download/极速下载/`（按类型分子目录），系统文件管理器和播放器可直接看到。
- 已导出文件的投屏采用零拷贝方式直接读取，不会把整个视频复制一份，大文件也能立即开始。
- 删除这类任务时，公共目录里的文件会一起删除。

## 19. 刷新链接保留断点与自动重试（v2.7.0 新增）

- **刷新链接保留断点**：直链失效需要换地址时，任务卡「失败 → 刷新链接」弹窗默认勾选
  「保留已下载进度继续」。应用会先探测新链接，只有**文件大小完全一致且支持 Range 分段**时才保留
  `.part` 进度从断点继续；否则自动清空重下并给出提示，避免出现"错位续传"。
- **网络瞬断自动重试**：瞬时断网、超时、5xx 会自动按 3s→10s→30s 退避重试，状态行显示
  「网络重连 n/3」。硬错误（404/403、校验不匹配、磁盘空间不足等）不会重试。
  在「下载设置 → 网络重连」可调整 0–5 次，0 表示失败即停。
- **空间前置校验**：新建大任务前先检查下载目录剩余空间，不足会明确报「需 X / 剩余 Y」，
  不再下到 99% 才失败。传输页顶部实时显示剩余空间。
- **任务详情**：点任务卡标题/进度区域弹出详情，可查看原始 URL 与最终重定向 URL（点击复制）、
  保存路径、HTTP 分段数或 BT 节点数等完整信息。

## 20. 浏览器净化与批量建任务（v2.7.0 新增）

- **广告拦截**：默认开启，自动拦掉常见广告/统计域名与脚本弹窗，并阻止影视站跳转到外部未知 App
  （只放行 http/https/magnet/about）。「下载设置 → 浏览器净化」可关闭，或按行追加自定义拦截规则
  （纯域名或含协议的地址，`#` 开头为注释）。
- **桌面/手机版切换**：地址栏右侧「⋮ → 切换为桌面版/手机版网页」，切换 UA 后自动刷新，
  用于让只在桌面端显示直链的网盘/下载站现出直链。
- **标签与长按**：标签胶囊右侧有 `×` 可直接关闭（长按也可以），切换时标签条自动滚动到当前标签；
  地址栏聚焦自动全选、右侧有 `✕` 清空；长按网页图片可保存/复制链接，长按超链接可新建下载/新标签打开/复制链接。
- **批量建任务**：「新建下载任务」输入框支持多行粘贴，可一次贴多条直链/磁力，点「批量识别链接」
  （或自动检测 ≥2 条）弹出带复选框的确认列表，支持全选/反选后一键建立全部任务。

## 21. 文件工具（v2.7.0 新增）

- **ZIP 安全解压**：长按 `.zip` 文件选「解压到同名文件夹」，后台解压到同名目录。
  解压会严格校验路径，含 `../` 等目录穿越条目会中止，防止恶意压缩包写出到目录之外。
- **文本快速查看**：`.txt/.log/.json/.srt/.ass` 长按选「快速查看」，内置弹窗只读前 512KB，
  避免打开超大日志卡顿。

## 22. 备份与恢复（v2.7.0 新增）

「我的 → 备份与恢复」可把配置打包成一个 JSON 文件，用于换机或重装后恢复：

- **导出**：调用系统文件选择器指定保存位置，文件名形如 `SwiftDownload_Backup_yyyyMMdd_HHmm.json`，
  内容包含书签、磁力源开关与自定义地址、广告拦截规则、全部下载设置。
- **导入**：选择备份 JSON，校验格式与版本后可选「合并」（保留现有项）或「覆盖」（先清自定义书签）。
  恢复后立即刷新书签、磁力源与下载设置。

> 备份文件包含你的代理地址、Cookie 相关设置等配置，请妥善保管，不要随意分享。

## 23. 界面与主题（v2.7.0 新增）

- 适配 Android 15/16（targetSdk 36）的 Edge-to-Edge：顶栏不再顶进状态栏、底栏不被手势条遮挡，
  弹出键盘时输入框自动上移。
- 应用锁定浅色主题，避免系统深色模式下弹窗文字与浅色卡片反差看不清。

## 24. 浏览器单手操作与抓资源（v2.8.0 新增）

- **底部工具栏**：浏览网页时，底部导航栏上方常驻 6 个按钮：`←` 后退、`→` 前进、`↻` 刷新、`☆` 收藏当前页、`⌂` 回首页（长按管理标签）、`🎬` 抓资源。不可后退/前进时按钮置灰。
- **极简顶栏**：网页态顶部只显示标题/域名与进度，点一下才展开完整地址输入框；首页只有搜索胶囊与 3 列书签方块（长按编辑/置顶/删除）。
- **一键抓资源**：在电影站/资源站打开页面后点 `🎬`，会扫描本页所有磁力链接、`.torrent`、电驴链接与 40 位 infohash，列出后勾选即可批量建下载任务，也可一键全部复制。按钮上的数字就是发现的资源数。
- **网页打不开时**：现在会自动走你在设置里填的 HTTP 代理；证书异常会弹窗询问是否继续；主框架加载失败会显示带「刷新 / 检查代理」的错误页，不再白屏。
- **去广告**：除请求级拦截外，开启「强力去除悬浮广告」后会注入 CSS 隐藏常见悬浮横幅与劫持层（默认关闭，避免误伤播放器）。

## 25. 磁力搜索更可用（v2.8.0 新增）

- **自己加源**：「我的 → 磁力源管理 → ＋ 添加新磁力源」，填名称、含 `{kw}` 的搜索地址即可；不确定解析规则留空走通用扫描。自定义源可长按改名、删除。
- **连通性自检**：源管理页点「测试连通性」，每个源会显示命中条数、403 被拦截、超时或网络不可达，域名失效一眼可见。
- **搜索明细**：搜索结束后点结果数那行状态文字，可展开看每个源命中几条、哪个源空壳/被拦截；对空壳或被 Cloudflare 拦截的源会自动启用离屏浏览器等 JS 渲染后重试，提高命中率。
- **BT 诊断**：磁力任务卡现在显示「等待元数据 · 已连 X 节点（DHT Y）」或下载速度/做种数，任务详情可见 Tracker 状态与 Peer 数，不再对着 0 B/s 干等。
